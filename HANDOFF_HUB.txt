==========================================================================================
WHAT  One browser app (stdlib Python server + one-file UI) that streamlines the user's projects:
      script -> HubGPT Voice -> pictures (ComfyUI) -> HubGPT Video (slideshow),
      + image studio, library, live job logs. Read README.txt for folders and features.
USER RULES  D: media, E: code, never C:; ask before install/delete (move to _old, never delete); every project
      standalone with its own setup (shared: ComfyUI, Ollama models, FFmpeg, D: media); keep him posted with
      short hints; spend his Claude usage carefully; ONE GPU job at a time.

  HubGPT is in E:\Projects\hub_chatgpt. Voice and Video are engines within HubGPT: engines\voice and engines\video.
  Their code and local video venv stay in this codebase. Trained voice checkpoints stay in engines\voice\models,

  14 Oct, so restart hub.bat after server changes before live browser verification.
